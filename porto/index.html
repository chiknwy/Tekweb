03 — Thesis

Research Highlight

Undergraduate Thesis · Feb 2026

Dual Wallet Authentication on Smart Contract Blockchain Using Node.js & JWT

Implementasi Autentikasi Dua Dompet pada Smart Contract Blockchain

This thesis proposes a novel authentication architecture that combines two blockchain wallet addresses as a dual-factor identity layer, secured by JWT tokens issued by a Node.js backend. Smart contracts on the Ethereum network enforce wallet ownership verification on-chain, while the off-chain JWT layer handles session management and API authorization — creating a hybrid Web2/Web3 security model that is both trustless and developer-friendly.

⛓
On-Chain
Smart contract enforces dual wallet ownership. Each authentication requires a cryptographic signature from both registered wallets.
🔐
Off-Chain
Node.js backend validates on-chain proof, then issues a signed JWT for stateless API session management.
🔑
Dual Factor
Two separate wallet addresses act as independent authentication factors — neither alone is sufficient to gain access.
